# HSMCP Test — the first campaign built by the tools

Two chapters, built entirely through this server's tools: no `.vmf` was edited by hand.

```
src/                      source .vmf files (committed)
addon/missions/           the campaign file (committed)
addon/addoninfo.txt       the addon manifest (committed)
addon/maps/               compiled .bsp (ignored; rebuilt)
hsmcp-test.vpk            packed addon (ignored; rebuilt)
```

## What the maps contain

Both maps are a sealed 768×512×192 room with a divider wall and a doorway.

| Map | Entities |
|---|---|
| `hsmcp_test_m1` | `info_player_start`, `light`, `info_director`, `info_zombie_spawn`, a `trigger_changelevel` brush pointing at `hsmcp_test_m2` |
| `hsmcp_test_m2` | the same, with a `trigger_finale` instead of a transition |

## Rebuild

From the repository root, after `pnpm build`:

```powershell
node campaigns/hsmcp-test/build.mjs
```

The script creates both maps, checks them sealed and lint-clean, compiles with Tools++,
writes the campaign file, checks it, and packs the addon. Output for the current build:
both maps compile clean, `check_campaign` → `pass`, VPK has 4 entries (two maps, mission,
manifest).

## Not playable yet

There is no `.nav` in the addon. Left 4 Dead 2's AI (Director, bots, specials) needs one,
and it can only be generated by the engine (`nav_generate`). Until Gate F answers whether
that is possible from `srcds` or needs the client, these maps are a compile-and-package
proof, not a playable campaign.
